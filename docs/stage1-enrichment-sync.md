# Обогащение водителей + синхронизация с БД (этап 1)

Дашборд-аналитика остаётся на данных таблицы; параллельно БД синхронизируется с
листом и обогащается контекстом по водителям. Это фундамент под этап 2 (отправка
в Telegram списков на забор денег с контактами/комментариями/документом).

## Поток данных

```
Google-таблица  ──(sync, идемпотентно)──►  БД ──► дашборд / ввод / профиль
   (платежи,                                │
    источник истины аналитики)              └── обогащение (телефон, адрес,
                                                 контекст, комментарии) — живёт
                                                 ТОЛЬКО в БД, синком не затирается
```

Платежи по-прежнему ведутся в таблице (привычная аналитика), а БД — зеркало +
носитель обогащения, которое понадобится сборщику.

## Обогащение водителя

Поля у `drivers`: `phone`, `address` (адрес встречи), `context` (памятка),
`in_park`. Комментарии — таблица `notes` (с автором и датой). Миграция 0003.

| Метод | Путь | Назначение |
|---|---|---|
| `GET` | `/api/drivers/{id}/profile` | контакты + контекст + комментарии + сводка долга |
| `PATCH` | `/api/drivers/{id}` | обновить phone/address/context/in_park |
| `POST` | `/api/drivers/{id}/notes` | добавить комментарий |
| `DELETE` | `/api/notes/{id}` | удалить комментарий |

UI: на странице `/entry` — кнопка **«Профиль»** в шапке выбранного водителя.
Модалка: контакты (редактируются), флаг «в парке», комментарии (добавить/удалить).

## Синхронизация лист → БД

Идемпотентный прогон, **обогащение сохраняется** (миграция трогает только платежи
и обязательства, поля `phone/address/context` и `notes` не затрагивает —
проверено: после ре-синка телефон/адрес/комментарии на месте).

```bash
# вручную
cd backend && python migrate_sheet.py --google --load     # из живой Google-таблицы

# по расписанию (cron, напр. каждый час)
0 * * * *  cd /opt/VTB-FL/backend && DATABASE_URL="postgresql+psycopg2://…" \
           python3 migrate_sheet.py --google --load >> /var/log/vtbfl-sync.log 2>&1
```

Сверка («ворота») в логе покажет расхождения; при нуле — данные синхронны.

## Проверено

```
PATCH контактов, добавление/удаление комментариев — ок
повторный sync из таблицы → обогащение НЕ затёрто (тел/адрес/контекст/коммент.) ✓
```
